# Jaeden Servantez Portfolio

A multi-page student portfolio for CSA 2328 Web Page Development. The site uses semantic HTML, a shared external stylesheet, Flexbox for navigation and flexible content areas, CSS Grid for the project gallery, and media queries for tablet and mobile layouts.

## Open the website
1. Download or clone this repository.
2. Keep `index.html`, `hobbies.html`, `contact.html`, `style.css`, and the `images` folder together.
3. Open `index.html` in a web browser. No build tools are required.

## Files
- `index.html` — portfolio, education, skills, and project gallery
- `hobbies.html` — personal interests
- `contact.html` — contact information and profile links
- `style.css` — shared styles, Flexbox, Grid, and responsive breakpoints
- `images/profile.jpg` — profile photo

## Responsive breakpoints
- Medium/tablet: `max-width: 850px`
- Narrow/mobile: `max-width: 520px`


## Project gallery links
The four gallery cards on the home page are clickable. They open the portfolio home page, these project notes, the Hobbies page, and the Contact page. Use a keyboard Tab to focus a card and press Enter to open it.
